# GeoProb-Pipe
Applicatie voor het uitvoeren van probabilistische piping berekeningen. De applicatie maakt gebruik van de 
probabilistische bibliotheek van Deltares. Deze bibliotheek stuurt onder de motorkap de PTK-tool aan.

# Installatie en quickstart
GeoProb-Pipe installeer je zoals je gewend bent van Python: `pip install geoprob_pipe`. GeoProb-Pipe is een terminal 
applicatie (TUI), je start hem middels het commando `geoprob_pipe`.  


# Mee ontwikkelen
Wil je bijdragen aan de ontwikkeling van GeoProb-Pipe? Dat kan! :)

Maak een nieuwe branch aan vanuit `alpha`, ga coden en wanneer je klaar bent, maak een pull en review request aan. Lees 
voor het maken van de review request even de richtlijnen in de repository README.
